# PHP & MySQL Pet Project

Легковесное веб-приложение с минималистичным дизайном, разработанное в качестве пет-проекта. Основная цель проекта — демонстрация базовых принципов бэкенд-разработки, работы с базами данных и чистоты архитектуры без перегрузки лишними фронтенд-фреймворками.

## 🛠️ Стек технологий

- **Язык программирования:** PHP 8.3
- **База данных:** MySQL 8.0
- **Фронтенд:** Стандартная верстка (HTML5 / CSS3 / JavaScript)
- **Локальное окружение:** OS Panel
- **Хостинг:** InfinityFree

---

## 🚀 Инструкция по локальному развертыванию

Для запуска проекта на локальном компьютере используется локальный сервер **OS Panel**.

### Предварительные требования
1. Установите и запустите [OS Panel](https://ospanel.io/).
2. Убедитесь, что в профиле OS Panel включены модули: **PHP 8.3** и **MySQL 8.0**.

### Пошаговая настройка

1. **Клонирование репозитория:**
   Клонируйте репозиторий в рабочую директорию ваших сайтов в OS Panel (например, `.../OS Panel/home/ваш-сайт.local`):
   ```bash
   git clone https://github.com/BibaPirat6/KorokNet.git .```

### Настройка базы данных:

1. Откройте **phpMyAdmin** через меню OS Panel.
2. Создайте новую базу данных (например, `pet_project_db`).
3. Перейдите во вкладку **Импорт** (Import), выберите SQL-дамп файл из репозитория (например, `database/schema.sql`) и нажмите **Вперед** (Go).

1. Найдите конфигурационный файл (например, `config.php` или `.env`).

### Запуск:

1. Перезапустите модули в **OS Panel**.
2. Откройте браузер и перейдите по адресу вашего локального домена (например, `http://localhost/` или `http://ваш-сайт.local`).
